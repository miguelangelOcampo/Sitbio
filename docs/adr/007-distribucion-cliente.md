# ADR-007: Distribución del cliente

- **Estado:** Propuesto
- **Fecha:** 22/10/2026
- **Drivers:** DRV-009

## Contexto

Ver el DOC-06 (secciones de drivers y del componente relacionado).

## Decisión

Publicación autocontenida win-x64, distribuida gratis por la página del proveedor (instalador Inno Setup) y por Microsoft Store (paquete MSIX); el cliente verifica la versión mínima al iniciar sesión.

## Consecuencias

- Instalador de mayor tamaño.
