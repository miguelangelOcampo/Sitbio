# ADR-010: Alojamiento del servicio

- **Estado:** Propuesto
- **Fecha:** 25/10/2026
- **Drivers:** DRV-001, DRV-009

## Contexto

Ver el DOC-06 (secciones de drivers y del componente relacionado).

## Decisión

API, bases de datos y archivos en la nube del proveedor (SaaS multi-tenant); la IPS solo instala el cliente.

## Consecuencias

- Disponibilidad y respaldos a cargo del proveedor; la IPS requiere Internet.
